Clear Problem Statement

Core Rationale

Commercial aviation consumers face severe market friction characterized by extreme pricing asymmetry, non-stationary fare volatility, and fragmented telemetry intelligence:

  • Stochastic Fare Surge Volatility: Airline revenue management systems deploy dynamic pricing algorithms driven by booking lead time, capacity exhaustion curves, competitor scraping, and demand elasticities. Fares fluctuate up to 38.4% within a 14-day window, leaving consumers unable to ascertain whether current rates represent a genuine dip or an impending surge.
  • Telemetry-Commercial Disconnect: Commercial flight search engines (Skyscanner, Google Flights, MakeMyTrip) provide static scheduling timetables disconnected from genuine live airspace status. Conversely, flight radar platforms (Flightradar24) track transponder telemetry but omit price prediction models, convenience indexing, and ticket acquisition workflows.
  • Subjective "Convenience" Calculation Deficit: Existing search tools sort flights almost exclusively by raw price or gross flight duration. They fail to systematically quantify multi-factor passenger convenience (e.g., biometric DigiYatra fast-track privileges, direct great-circle routing, cabin amenities, and punctuality buffer times).
  • Desktop Information Fragmentation & Missing Boarding Windows: High-volume desktop travelers require immediate visibility into critical time windows (specifically Boarding Commencement Time and Gate Closing Cutoffs), yet traditional portals bury boarding timelines deep inside post-purchase email attachments or separate airline apps.
AeroTrack Unified Solution: Bridges physical 1090 MHz Mode-S transponder streams from OpenSky Network, a 30-day predictive Machine Learning fare forecast engine, an objective Multi-Factor Convenience Index, a Skyscanner-grade conversational search console, and a dedicated Desktop Screen Boarding Time HUD.

Research Gap & Novelty

Innovation Matrix

A systematic analysis of contemporary literature indicates that prior research remains compartmentalized into either aerospace transponder signal tracking or econometric airline revenue management.

Identified Core Research Gap: No existing software platform simultaneously unifies real-time physical transponder vector streaming with predictive machine learning price drop detection, biometric airport convenience scoring, and a responsive desktop boarding alert HUD.

AeroTrack Novel Contributions:

  1. Dual-Mode Hybrid Architecture: Capable of operating as a full-stack Node.js/Express + MongoDB server or dropping into zero-dependency standalone mode on static web edge nodes (e.g. GitHub Pages) using in-memory dead-reckoning.
  2. Selective Corridor Radar Decluttering: Eliminates visual aircraft swarms by dynamically isolating only flights matching the selected flight's origin/destination corridor.
  3. Objective Multi-Factor Convenience Formula: Algorithmically computes passenger utility score (50–98%) combining biometric DigiYatra fast-track privileges, non-stop routing, departure slot convenience, and seat pitch.

Dataset Technology & Live ADS-B Ingestion Engineering

Big Data Pipeline

AeroTrack ingests live positional vectors via the OpenSky Network API across the Indian subcontinent bounding box (Latitude 8.0°N to 35.0°N, Longitude 68.0°E to 95.0°E). The raw vector format consists of a 17-field tuple:

StateVector = [ icao24, callsign, origin_country, time_position, last_contact, longitude, latitude, baro_altitude, on_ground, velocity, true_track, vertical_rate, sensors, geo_altitude, squawk, spi, position_source ]

Between 11-second API bursts, AeroTrack's client and server engines execute continuous dead-reckoning at 2.5-second intervals using spherical trigonometry to project aircraft latitude, longitude, and progress seamlessly.

Machine Learning Model Analysis

Predictive Analytics

AeroTrack incorporates machine learning regression and classification to estimate passenger purchase timing:

  • Feature Vector Representation: Includes lead time $T_{\text{lead}}$, route distance $D$, historical route variance $\sigma_{\text{route}}$, seat occupancy ratio $\rho$, day-of-week cyclical encoding $(\sin(2\pi d/7), \cos(2\pi d/7))$, and festival surge multipliers.
  • Surge Classification (Buy Now vs Wait): An ensemble threshold model compares the current price $P_{\text{current}}$ against the rolling 30-day forecasted mean $\mu_{\text{forecast}}$. If $P_{\text{current}} \le \mu_{\text{forecast}} - 0.12\sigma$, the system emits a "Strong Buy / Historic Low" signal.

Knowledge Deep Dive: Random Forest Forecast Aggregation (Future Scope)

Next-Gen Architecture

To scale dynamic fare forecasting across hundreds of domestic and international corridors simultaneously, AeroTrack designs a Random Forest Ensemble Aggregator for future deployment:

\hat{P}_{\text{ensemble}}(x) = \frac{1}{B} \sum_{b=1}^{B} T_b(x; \Theta_b)
Where $B$ is the number of decorrelated decision trees (typically $B=150$), $x$ represents the feature vector of airport pairs, fuel indices, and booking intervals, and $\Theta_b$ is the bootstrapped parameter subspace.

By aggregating uncorrelated tree predictions, the model mitigates single-estimator overfitting during anomalous festive booking sprees (e.g. Diwali and New Year holiday price spikes).

Outcomes, Conclusion, Flaws & Future Roadmap

Critical Evaluation

15.1 Project Outcomes & Conclusions

AeroTrack successfully realizes a unified aerospace intelligence platform merging physical radar tracking with commercial fare analytics. The system delivers 60 FPS geospatial visualization, robust dual-mode execution, and Skyscanner-grade search usability.

15.2 Architectural Flaws & Limitations

  • OpenSky Rate Limits: Anonymous public OpenSky API requests are capped at 400 requests/day, requiring intelligent local dead-reckoning caching.
  • Transponder Coverage Discontinuities: ADS-B ground stations have limited oceanic and Himalayan coverage, necessitating mathematical geodesic interpolation.

15.3 Future Scope Roadmap

  1. Integration with Airline GDS NDC APIs: Connect direct Amadeus / Sabre New Distribution Capability feeds for instant live seat reservation.
  2. CO2 Emissions Optimization: Model environmental flight efficiency based on aircraft engine type and actual flight level altitudes.
